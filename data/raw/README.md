# Raw data

This directory contains source datasets used by the project.

## P&G financial highlights

Expected file: `pg/pg_financial_highlights.csv`

The file contains selected, rounded company-level financial highlights for fiscal years 2022–2026. Verify each value against the official P&G annual reports before relying on it or publishing the project.

Official sources:
- https://www.pginvestor.com/financials/annual-reports/default.aspx
- https://s204.q4cdn.com/332108499/files/doc_financials/2026/ar/2026_annual_report.pdf

## FMCG dataset

Expected file: `fmcg/FMCG_2022_2024.csv`

Source:
https://www.kaggle.com/datasets/beatafaron/fmcg-daily-sales-data-to-2022-2024

The dataset is described by its publisher as synthetic. It is not actual P&G sales data.

Check the dataset licence and attribution requirements before redistributing the original file.

Raw data should remain unchanged. Quality flags and transformations are applied in the analysis scripts rather than by editing the source files.
